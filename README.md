# SillyTavern Auto Rewrite（正文重写 · 独立版）

让 SillyTavern 在回复生成后再自动（或手动）重写一轮的扩展，**不需要改酒馆本体**，官方原版酒馆直接安装就能用。

## 为什么做这个扩展

很多时候模型第一轮直出容易写歪、台词油腻或者逻辑跟不上，但自己在聊天里手动发一句“重写”又会把废话留在记录里占上下文。

这个扩展把“重写一轮”自动化了：第一版写完后临时让模型审视前文重来一遍，写完再把临时指令清理掉，把结果放回原楼。

## 怎么工作的

点正文底部的 **「重写」**（或打开 **「自动」** 开关）后，扩展会等这一轮保存完成，然后在后台按正常对话流程跑一遍重写：

1. 在聊天末尾**临时加一条修改意见**，调用酒馆原本的生成功能再跑一轮（所以你原本的预设、世界书、正则、流式输出和思考过程都照常生效）。
2. 重写过程中可以实时看到流式输出。
3. 写完后，自动把刚才那条临时修改意见和临时楼层删掉，把第二版放回原本那一楼，原稿保留为同一楼的旧版本（Swipe）。

聊天记录里不会多出多余楼层，也不会自己接着触发第三轮。

## 主要功能

- **底栏操作条（与翻页胶囊同一行）**：在最新一条角色回复底部提供「重写」「查看原稿 / 返回重写版」「自动」开关和设置入口，在原稿和重写版之间切换不会重新请求模型。
- **自动重写**：默认关闭；打开后每次新生成回复（包括点右箭头新抽卡）都会自动重写一轮，只翻看已有旧版本不会触发。
- **自定义修改意见**：点底栏设置图标或扩展面板里的「正文重写 · 独立版」，可以自己修改发给模型的重写要求。
- **原生停止与防丢稿**：中途按酒馆自带的停止按钮就能取消，失败或取消时会自动清理临时消息并恢复原稿。

## 安装方法

在酒馆的 **扩展 → 安装扩展** 中直接填入仓库地址：

```text
https://github.com/wujimol/SillyTavern-Auto-Rewrite
```

或者手动下载源码，将 `index.js`、`revisions.js`、`ui.js`、`manifest.json`、`style.css` 放到酒馆的第三方扩展目录下，刷新页面即可。

> 如果之前装过旧的定制版，建议先禁用或替换掉旧版，避免两个扩展同时触发。

## 使用注意与兼容说明

- **预设与数据库兼容**：因为完全走酒馆原生对话流程，普通对话流预设基本都能正常使用；但如果用的预设或数据库插件会在第一轮就直接写入变量/总结，或者会主动删除历史正文，第二轮重写时的适配效果目前有待检验。
- **额度消耗**：每次重写会多发一次模型请求，开启自动重写时单轮会消耗两轮额度。
- **适用范围**：目前只支持单角色聊天；群聊、开场白和纯空白回复不会触发。
