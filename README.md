# SillyTavern Auto Rewrite

一个仅负责自动重写的 SillyTavern UI 扩展，不需要修改酒馆本体，不依赖其他第三方扩展。

## 工作方式

开启后，每次生成一条有正文的单角色回复，扩展等待酒馆结束生成、释放流式对象并完成保存，然后追加修改意见作为一条普通用户消息，再通过酒馆原生生成入口生成一次新回复：

```text
user: 本轮要求
assistant: 第一版正文
user: 修改意见：请重写上一条，不要续写……
assistant: 第二版正文
```

第一版、修改意见、第二版都是正常保存的聊天记录。不会重复复制第一版，不会覆盖第一版，不把第二版折叠成同一楼的回复版本。扩展自身不会继续触发第三轮。

## 安装与使用

在酒馆“扩展 → 安装扩展”中填写：

```text
https://github.com/wujimol/SillyTavern-Auto-Rewrite
```

也可将源码中的 `index.js`、`manifest.json`、`style.css` 放进一个扩展目录，安装到酒馆的用户扩展目录或 `public/scripts/extensions/third-party/auto-rewrite`。刷新页面，在扩展设置中展开“自动重写 · 独立版”，填写修改意见并开启自动开关。新安装默认关闭；不会追溯重写打开页面前的历史回复。

与旧定制版替换到同一个目录时，沿用已有的自动开关和修改意见。安装到新目录时，应先禁用旧的重写扩展，避免两个扩展同时自动生成。

## 范围

- 只保留自动开关和修改意见；使用酒馆当前的连接、模型和预设。
- 支持普通生成、重新生成和右箭头生成的新版本；只翻阅旧版本不会触发。
- 仅支持单角色聊天；不自动重写开场白、后台请求或没有正文的回复。
- 输入框有草稿、待发送附件或消息正在编辑时暂缓；发送新消息或切换上下文会取消旧队列。
- 使用酒馆原有停止按钮。停止或失败后，已有原稿、修改意见和收到的回复按正常聊天记录保留；不会自动重试。
- 关闭自动开关只取消尚未开始的队列；已经发出的第二轮可用原生停止按钮取消。

## 预设兼容

扩展不编辑预设，不重排最终 API 请求，不直接调用模型接口，不使用自定义 `Generate()` 参数，不拦截 `fetch`，也不解析预设的工具协议。修改意见是正常的用户消息，之后仍由酒馆及现有预设执行上下文处理、世界书、正则、工具调用与防截断逻辑。

这保留原生处理路径，但不能保证所有预设都兼容。预设可能主动删除历史正文、限制上下文、忽略修改意见或在第一轮就写入变量和总结；扩展不会撤销这些副作用。模型是否分段返回也由模型与渠道决定。

## 实现与验证状态

使用官方 `release` 分支可见的上下文、生成事件、聊天渲染和普通生成接口。等待 `streamingProcessor` 被酒馆释放后再开始第二轮，避免依赖定制版的收尾标记。

当前版本完成了源码接口对照，未运行自动测试、构建、浏览器回归或真实模型请求；尚未声称已在原版酒馆上完成运行验证。
